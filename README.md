# Telecom Customer Data Science Project

## 📌 Project Overview

This project focuses on analysing telecom customer data using Python and basic Data Science techniques.

The main purpose of this project is to understand customer information, explore service and billing patterns, analyse customer behaviour and identify useful insights from the available data.

## 🎯 Objectives

- Understand the telecom customer dataset
- Inspect rows, columns and data types
- Check missing values and duplicate records
- Perform data cleaning
- Perform Exploratory Data Analysis (EDA)
- Analyse numerical and categorical variables
- Create meaningful data visualisations
- Study relationships between numerical variables
- Analyse customer churn patterns
- Generate useful data-driven insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Google Colab

## 🔍 Project Workflow

1. Data Loading
2. Data Inspection
3. Data Cleaning
4. Descriptive Statistics
5. Exploratory Data Analysis
6. Data Visualisation
7. Correlation Analysis
8. Customer Churn Analysis
9. Key Findings
10. Conclusion

## 📊 Analysis Performed

The project includes analysis of:

- Customer information
- Numerical variables
- Categorical variables
- Service-related information
- Billing-related information
- Customer churn
- Relationships between numerical variables

The project can be further extended by using feature engineering and Machine Learning techniques for customer churn prediction.
