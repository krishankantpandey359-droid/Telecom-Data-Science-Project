# Mobile Phone Specifications Data Analysis

## 📌 Project Overview

This project performs exploratory analysis of a 50-row mobile phone specifications dataset using Python.

The analysis examines device connectivity, display, camera, memory, battery, weight and price fields.

## 🎯 Objectives

- Understand the mobile phone specifications dataset
- Inspect rows, columns and data types
- Check missing values and duplicate records
- Perform data cleaning
- Perform Exploratory Data Analysis (EDA)
- Analyse numerical and categorical variables
- Create meaningful data visualisations
- Study relationships between numerical variables
- Analyse relationships between phone specifications and price
- Generate useful data-driven insights

## 🛠️ Technologies Used

- Jupyter Notebook
- Google Colab
